# ACG720 机器人 接线表（P7 扩展排针）

P7 是板子上那排 40 针的扩展排针（2 行 × 20 列）。
找 1 脚：PCB 上 1 脚焊盘通常是方形，其余是圆形；也可以用万用表确认 —— 第 29 针对地应为 3.3V，第 11 针对地应为 5V。

| P7针号 | FPGA脚 | 接到哪里 |
|---|---|---|
| 1 | A13 | **m_pwm[0]** — 左前 电机PWM  -> TB6612#1 PWMA |
| 2 | A14 | **m_in1[0]** — 左前 IN1      -> TB6612#1 AIN1 |
| 3 | A15 | **m_in2[0]** — 左前 IN2      -> TB6612#1 AIN2 |
| 4 | A16 | **m_pwm[1]** — 左后 电机PWM  -> TB6612#1 PWMB |
| 5 | A18 | **m_in1[1]** — 左后 IN1      -> TB6612#1 BIN1 |
| 6 | A19 | **m_in2[1]** — 左后 IN2      -> TB6612#1 BIN2 |
| 7 | F13 | **m_stby[0]** — TB6612#1 STBY |
| 8 | F14 | **m_pwm[2]** — 右前 电机PWM  -> TB6612#2 PWMA |
| 9 | E13 | **m_in1[2]** — 右前 IN1      -> TB6612#2 AIN1 |
| 10 | E14 | **m_in2[2]** — 右前 IN2      -> TB6612#2 AIN2 |
| 11 | — | **5V** 电源脚 |
| 12 | — | **GND** 电源脚 |
| 13 | C13 | **m_pwm[3]** — 右后 电机PWM  -> TB6612#2 PWMB |
| 14 | B13 | **m_in1[3]** — 右后 IN1      -> TB6612#2 BIN1 |
| 15 | D14 | **m_in2[3]** — 右后 IN2      -> TB6612#2 BIN2 |
| 16 | D15 | **m_stby[1]** — TB6612#2 STBY |
| 17 | C14 | **enc_l_a** — 左侧编码器 A 相 (只接前轮一个) |
| 18 | C15 | **enc_l_b** — 左侧编码器 B 相 |
| 19 | B15 | **enc_r_a** — 右侧编码器 A 相 |
| 20 | B16 | **enc_r_b** — 右侧编码器 B 相 |
| 21 | D17 | **us_trig[0]** — 左 超声波 TRIG |
| 22 | C17 | **us_echo[0]** — 左 超声波 ECHO |
| 23 | E16 | **us_trig[1]** — 中 超声波 TRIG |
| 24 | D16 | **us_echo[1]** — 中 超声波 ECHO |
| 25 | B17 | **us_trig[2]** — 右 超声波 TRIG |
| 26 | B18 | **us_echo[2]** — 右 超声波 ECHO |
| 27 | C18 | **imu_cs_n** — IMU CS |
| 28 | C19 | **imu_sclk** — IMU SCL/SCLK |
| 29 | — | **3V3** 电源脚 |
| 30 | — | **GND** 电源脚 |
| 31 | F16 | **imu_mosi** — IMU SDA/MOSI |
| 32 | E17 | **imu_miso** — IMU AD0/MISO |
| 33 | D20 | **estop_ok** — 急停：常闭按钮一端接P7-29(3V3)，另一端接这里；内部下拉 |
| 34 | C20 | 备用 |
| 35 | E19 | 备用 |
| 36 | D19 | 备用 |
| 37 | F18 | 备用 |
| 38 | E18 | 备用 |
| 39 | F19 | 备用 |
| 40 | F20 | 备用 |
